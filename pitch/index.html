05 · Research workflow

Designed to move beyond plausible text.

The value is not just generating an answer. It is giving the researcher a disciplined starting point for checking an idea.

◎

Make it falsifiable

What result would count against the hypothesis? What observation would change our mind?

⌁

Compare against a baseline

Plan a meaningful comparison rather than reporting a result without context.

▥

Measure what matters

Define success metrics and practical trade-offs before running the experiment.

↻

Make it reproducible

Record procedures, settings, limitations and the evidence needed to support conclusions.

06 · Honest by design

Useful today. Clear about its limits.

Implemented in prototype

What works in the current design

Idea and configuration inputs, a Python API route, OpenAI integration, schema-constrained research-plan generation, and a web interface designed to display the result.

Not yet automated

What it does not claim

It does not independently verify literature, prove novelty, execute experiments, or validate generated claims. Live API generation also depends on valid credentials, available quota, and service availability.

Current demo note

The presentation's plan generator is simulated locally. The deployed application's live generation previously returned an insufficient-API-credit error. Do not present the simulated sample as a live model response.
